Typography

Utility classes vs raw tokens. The six .text-* utility classes bundle four things: font-size, font-weight, colour and line-height. The raw --text-xs/-sm/-base/-md/-lg/-xl/-display tokens give you only font-size.

Reach for a utility class first — that's the contract for "this is the body / a heading / a label". Reach for the raw token when you need a custom combo (e.g. --text-md at weight 500 in --text-muted) that doesn't match any of the six.

Solid stops, not opacity

The brand intentionally has no rgba() overlay tokens. Semi-opaque values composite against whatever sits underneath, so the same token can read differently in different contexts and won't render correctly in canvas/image-generation. Use the shade ladder above instead. "White on navy at 18%" should be a solid --navy-300 (or whichever stop matches your background).

rgba(255,255,255,0.18)

Don't — opacity overlay. Renders differently on different backgrounds, breaks in canvas.

var(--navy-400)

Do — solid stop. Identical render in every context.

Club Picker

Two variants share the same shell, dropdown and option styling. Use .club-picker when freetext should be allowed (cup fixtures, opponent name where the club isn't in the NL list). Use .club-picker .club-picker--select when only the curated list applies and typing makes no sense (admin "focus on a club" pickers, etc.).

Formatting toolbar — .fmt-toolbar

Rich-text formatting bar promoted from graphics/article-composer. Any tool that grows a longform input (notes, descriptions, prompts) can drop this in verbatim — it pairs with a contenteditable="true" div and the standard document.execCommand wiring.
