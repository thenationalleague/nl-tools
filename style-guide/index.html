Canonical visual reference for /tools/system/nl-brand.css and /tools/system/nl-utils.js. Preview font and spacing changes here before deploying, and use it to settle "is X already a brand token?" before adding a tool-local one.

The brand has no rgba() overlay tokens by design. Semi-opaque values composite against whatever sits underneath, so the same token reads differently in different contexts and won't render in canvas exports. "White on navy at 18%" should be a solid --navy-300 (or whichever ladder stop matches).

rgba(255,255,255,0.18)

Don't — opacity overlay. Different render on different backgrounds, breaks in canvas.

var(--navy-400)

Do — solid stop. Identical render in every context.

Use .club-picker .club-picker--select when only the curated list applies and typing makes no sense (admin "focus on a club" pickers, etc.).

Identity palettes — tool-internal

These stay local to their tool — they're meaningless outside that context, or the data semantics are owned by an external system. Don't duplicate them; if you need similar shades, reach for the shade ladder or a semantic token first.
