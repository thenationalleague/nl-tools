NL Tools — Style Guide

All widgets and components from /tools/system/nl-brand.css. Use this to preview font and spacing changes before deploying.

📐 This is the source of truth for tool styling. Don't reinvent these components in your tool. Use the utility classes shown below and the tokens from nl-brand.css. The brief written form of these rules lives at system/_template/BRAND_GUIDE.md.

primary

Typography

Six utility classes — each bundles size, weight, colour and line-height. Apply one class to get the right combination. Tokens (--text-xs through --text-xl) are available in :root for direct CSS use when a utility class isn't appropriate.

.text-display--text-xl · Black 900
Display heading
.text-heading--text-lg · Black 900
Section heading
.text-subhead--text-md · Bold 700
Subheading / card title
.text-body--text-base · Regular 400
Body copy — The quick brown fox jumps over the lazy dog. National League tools use Carbona variable throughout.
.text-secondary--text-sm · Regular 400 · muted
Secondary text, hints, descriptions, timestamps and supporting copy.
.text-label--text-xs · Bold 700 · uppercase
Kicker / label / fine print
Font — Carbona variable

Always use var(--font). Never substitute system fonts for NL interfaces. Always pair font-weight with font-variation-settings.

Colour Contexts
White on Primary Red

Used in topbar, login background, primary buttons. Always white text on red.

White on Navy

Used in table headers, section headers, modal heads. Always white text on navy.

Text on white / off-white

Secondary text and labels use --text-muted. Primary copy uses --text. Never reverse these.

Buttons

Use .btn + a variant. Add .btn--sm for compact rows. Disabled state and focus ring are handled by the base class.

<button class="btn btn--primary">Primary action</button>
<button class="btn btn--navy">Navy action</button>
<button class="btn btn--ghost">Ghost / secondary</button>
<button class="btn btn--danger">Danger</button>
<button class="btn btn--restore">Restore</button>

<!-- Compact size for toolbars and inline actions -->
<button class="btn btn--primary btn--sm">Primary sm</button>

Don't roll your own. If you need a button shape that's not here, add the variant to nl-brand.css and document it here — don't style it inline in a tool.

Use .tabs as the row container and .tab for each tab. Add .is-active to the current one.

Toasts

Use NL.toast(msg, type) from nl-utils.js. Don't render toast HTML by hand. Types: success, error, info.

NL.toast('Saved successfully', 'success');
NL.toast('Could not save — try again', 'error');
NL.toast('Heads up — new version available', 'info');
Modals

Two sizes: default and .modal--wide. Add .is-open to show. The backdrop is part of .modal itself — no separate .modal-backdrop usually needed.

Confirm removal

This will delete the record permanently. Are you sure?

Edit vacancy

<div class="modal" id="myModal">
  <div class="modal__head">
    <h3>Confirm removal</h3>
    <button class="modal__close">&times;</button>
  </div>
  <div class="modal__body">…</div>
  <div class="modal__footer">
    <button class="btn btn--ghost btn--sm">Cancel</button>
    <button class="btn btn--danger btn--sm">Delete</button>
  </div>
</div>

<!-- Show / hide -->
modal.classList.add('is-open');
modal.classList.remove('is-open');
