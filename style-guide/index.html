Buttons

13px Black 900 uppercase. SM variant: 12px, 8px/14px padding. All support :disabled (opacity 0.5). Always pair with an icon where an action has a standard symbol.

Class Default Hover Disabled SM variant Use for
.btn--primary Main CTA. One per form/section. Red bg, white text.
.btn--navy Secondary CTA. Section headers, admin actions.
.btn--ghost Cancel, secondary. Bordered, white bg. Most common in toolbars.
.btn--danger Destructive actions (delete, remove). Red-tinted, NOT --primary red.
.btn--accent Highlight action within a dark/coloured surface.
.btn--restore Undo / restore defaults. Green-tinted positive action.
