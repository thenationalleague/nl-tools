NL.clubPicker

Live sandbox for the shared club picker. Change the options and the picker rebuilds; pick a club to see the onSelect payload. The secondary field control drives the right-hand text on each row (division etc).

Wired example: a division selector drives the picker

The <select> below is the tool's own control (not part of the picker). Changing it calls picker.setDivisions([…]) then picker.refresh(), so the club list re-scopes. All is the default and shows the whole roster.

Freetext example: type an off-roster club, click away to commit

A freetext:'commit' picker (transfer-centre style). Type an EFL club like Bolton Wanderers, then click the next field (or press Tab). It commits on blur and the crest resolves from crests/<name>.png. This picker is stable (the controls above don't rebuild it), so blur-commit works cleanly here.
