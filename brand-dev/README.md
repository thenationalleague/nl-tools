# brand-dev/ — brand development mockups

Internal meta-tooling, the same family as Estate and the Style Guide: pages
about the estate rather than pages of it. This directory holds static mockups
for brand direction work — currently the three v3 type-scale mocks
(`portal`, `tasks`, `travel-planner`) belonging to the parked
[`system/brand-v3-scale-plan.md`](../system/brand-v3-scale-plan.md).

Lived at `system/brand-v3-mockups/` until 15/08/2026. Moved because it is a
working surface, not system plumbing — and because its pages carried
`file:///home/user/tools/...` asset paths, meaning they had only ever rendered
on the machine that made them. They render on nl.tools now.

Ground rules:

- **Mockups, not tools.** Nothing here is gated, registered, or linked from
  the portal. No `?v=` contract, no auth-guard, no registry record.
- **Exempt from the canon-override count** (`scripts/check-canon-overrides.js`)
  and inventoried as sandbox by Estate — a mock exploring a *future* brand is
  allowed to disagree with the current one. That is its job.
- A mock that has served its purpose gets deleted, not archived here. The plan
  document it belonged to records the conclusions; git keeps the pixels.
