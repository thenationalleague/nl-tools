Read-only, live from assets/data/clubs-meta.json — the single source of truth the embeds, widgets and graphics tools all read. Columns are derived from the JSON, so new fields (e.g. lat/lng/nickname) appear automatically. The Season switcher filters to the clubs that played that season and shows each club's division for that season; all other fields are the latest value (sponsors, kit, capacity etc. aren't snapshotted per season). Download CSV exports the current filtered view (all columns) — that flat file doubles as the fill-in template for new clubs.
