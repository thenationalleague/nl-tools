Station distance calculator

Computes by-road distance (miles) from each club’s ground to its named station, using OpenStreetMap’s Nominatim (geocoding) + OSRM (routing). Nothing is saved — copy the JSON at the bottom and paste it back to Claude to drop into clubs-meta.json. Rows ≥ 20 mi (amber) are likely a bad station match — check the matched name.

Ready. Reads the live clubs-meta.json (~1 second per club, so ~1–2 min).
