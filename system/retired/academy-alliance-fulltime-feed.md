# Academy & Alliance — the Full-Time feed

Retired 11/09/2026, one day after it was built. The graphic itself
(`graphics/academy-alliance/`) is alive; this is the record of its feed.

## What it was

The Academy and U19 Alliance publish on FA Full-Time (fulltime.thefa.com),
which has no JSON feed and no CORS. Three attempts to read it unattended:

1. **A scheduled Cloud Function** (`functions/fulltime.js`, #1212) fetching each
   division's table, results and fixtures pages and writing
   `app-data/staff-graphics/fulltime/<division>`, with an RTDB trigger for an
   on-demand refresh. Every page of every division answered **HTTP 403,
   "Attention Required!"** — Cloudflare's block page — from Google's address
   space. Browser-like headers changed nothing (#1213).
2. **A GitHub runner with real headless Chrome** (`Probe FA Full-Time`, #1214,
   run 1): the same 403, plain fetch and Chrome alike. Full-Time refuses cloud
   address ranges outright, not just bots.
3. **A bookmarklet in the user's own browser** (#1215): run on a Full-Time
   page, fetch all 33 pages same-origin, hand them to the tool in a popup.
   A one-line test proved the fetch is allowed there. In use it did not work
   for the owner and was withdrawn the same morning without diagnosis.

## What survives

- The paste box understands rows copied straight off Full-Time: the table page
  (with its Home / Away / Overall columns — the overall set is printed), the
  fixtures table (pair either side of VS, kick-off from the date cell,
  Postponed dropped), and the results page, which copies out one field per
  line and is folded back on the score line. Pinned in
  `tests/academy-alliance-names.test.mjs`.
- The eleven Full-Time division IDs, season 395289686 (2026-27), in case a
  route ever opens: Academy North 355815748, Academy South 681316394,
  Alliance A 308197696, B 531392282, C 484327210, D 900324610, E 996619526,
  F 86586371, G 637572765, H 272864635, I 421309651. Results and fixtures
  pages accept `/results/1/100.html?…` and `/fixtures/1/100.html?…` for 100
  rows a page.
- The HTML parsers (`functions/fulltime/parse.js`, tests, saved pages) are in
  git history at #1215's merge commit, tested against pages saved 10/09/2026.

## The settled decision

Do not build a server-side fetch of Full-Time again: the FA blocks it at the
edge and nothing in this repo can change that. The only routes left are an
official Full-Time widget or data feed generated by a league administrator
(served to be embedded, so not blocked), or a formal ask to the FA for API
access. Neither was pursued; the owner chose paste.
